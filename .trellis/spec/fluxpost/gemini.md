# Canvas Gemini

Confirmed 2026-10-19. Gemini is a native text/vision provider, scoped to Canvas `model.gemini` v1. Real provider acceptance remains pending.

- Multi-text `prompt` and optional ordered `images` inputs produce one `text` artifact. Node `instruction` is prepended to prompt values; blank node `model` uses the global default. Bypass copies prompt text only. Ordinary runs, V2 schedules and image-iteration inner graphs accept this node.
- Admin advanced config allow-lists `GEMINI_API_KEY`, `GEMINI_BASE_URL`, `GEMINI_MODEL`, `GEMINI_PROXY_ENABLED`, `GEMINI_PROXY_URL`, `GEMINI_REQUEST_TIMEOUT_MS`. Defaults: Google `/v1beta`, empty model/key, proxy off/address `http://127.0.0.1:10808`, total deadline 180000ms. Config saves update the process-global config; each request snapshots settings before asynchronous work.
- `src/lib/gemini.ts` POSTs `/models/{model}:generateContent` with `x-goog-api-key`, one user content and TEXT modality. Ordered `inlineData` uses signature-checked JPEG/PNG/WebP. Limits: 8 images, 7MiB each, serialized UTF-8 JSON <=20,000,000 bytes. No automatic image conversion, dropped inputs, provider failover, retry or Files API.
- Existing runtime materialization and owner-checked local-directory snapshots supply bytes. Temporary downloads always clean up. The shared `gpt` pool, image reads, network and body consumption use the combined caller/deadline signal. Gemini proxy configuration is independent of the image-generation proxy, with one dispatcher per call.
- Missing key/model or invalid node model maps to Canvas `needs_config`. HTTP errors expose status/guidance only; blocked, truncated, empty and thought-only answers fail. Only non-thought text from the first candidate reaches downstream. Logs exclude prompts, media, raw provider payloads, URLs and secrets.
- `node .trellis/verification/canvas_gemini_check.mjs` uses a loopback provider/proxy and isolated media. `python .trellis/verification/canvas_gemini_browser_check.py` covers three themes at 1440/390 with intercepted Canvas/config APIs. `BROWSER_BASE_URL` must be worker-disabled loopback, never port 3001. Source and built config checks cover API/worker synchronization and secret non-disclosure. No live Gemini calls belong in the baseline.
