# 取消付费节点提示并增加画布快捷键

## Goal

让桌面端无限画布能够像 ComfyUI 一样通过键盘快速运行、中断和完成常用编辑操作，同时去掉付费模型节点每次运行前的重复付费提示。

## Background

- `src/app/canvas/page.tsx` 已提供运行全部、仅运行当前节点、运行到当前节点和取消当前运行的按钮。
- 运行请求先调用计划接口；当前只要计划包含 `text_model`、`image_model`、`video_model` 或 `external_write` capability，就显示同一个确认弹窗。
- 当前桌面快捷键包括原生复制/剪切/粘贴、`Delete`/`Backspace` 删除节点、`Tab` 打开快速添加和 `Ctrl/Cmd+D` 复制节点副本。
- 表单、选择框及可编辑区域已经通过 `isEditableClipboardTarget` 与画布级快捷键隔离，新增快捷键必须延续此规则。
- 画布运行和取消 API 已存在，不需要新增服务端任务接口。

## Requirements

- 所有 capability 确认都取消，包括付费模型与 `external_write` 外部写入；计划通过预检后直接入队，以支持后续无人值守的批量执行。
- 仍要执行现有运行预检、阻断规则、自动保存和服务端确认契约，不能通过快捷键绕过配置校验。
- 桌面端增加 ComfyUI 风格快捷键：`Ctrl/Cmd+Enter` 运行全部、`Ctrl/Cmd+Alt+Enter` 中断当前运行、`Ctrl/Cmd+S` 保存、`Ctrl/Cmd+Z` 撤销、`Ctrl/Cmd+Y` 或 `Cmd+Shift+Z` 重做、`Ctrl/Cmd+A` 全选。
- 保留并统一现有常用键位：`Ctrl/Cmd+C/X/V` 复制/剪切/粘贴、`Ctrl/Cmd+D` 复制节点副本、`Delete/Backspace` 删除、`Tab` 快速添加。
- 撤销/重做覆盖当前工作流的节点、连线与视口，使用有限长度的会话内历史；切换工作流时重置，不新增持久化格式。
- 快捷键在输入框、文本域、选择框和 contenteditable 内不触发画布命令，并兼容 Windows/Linux 的 `Ctrl` 与 macOS 的 `Cmd`。
- 现有可点击命令继续作为快捷键对应入口；为相关按钮补充 `aria-keyshortcuts`，不新增可见的快捷键说明面板；移动端不启用键盘命令。
- 保留现有按钮操作和已有快捷键，不改变 API、数据库或工作流 JSON 结构。

## Acceptance Criteria

- [x] 含付费模型或外部写入能力的可执行计划都可直接入队，不显示确认弹窗或付费提示。
- [x] `Ctrl/Cmd+Enter` 可运行全部节点；`Ctrl/Cmd+Alt+Enter` 可对运行中的任务触发既有取消流程。
- [x] 保存、全选、复制/剪切/粘贴、复制副本、删除和快速添加键位按需求工作；相关可点击按钮带准确的 `aria-keyshortcuts`。
- [x] 撤销/重做按编辑操作恢复节点、连线和视口，重做分支在新的编辑后清除，历史有明确上限且切换工作流后不串线。
- [x] 快捷键在可编辑控件中不拦截输入、换行、复制粘贴或删除。
- [x] 无画布、无节点、无选中节点、任务忙碌或无可取消运行时，相应快捷键安全地不执行。
- [x] 现有点击操作、自动保存、运行预检、运行历史轮询和移动端检查/运行模式保持可用。
- [ ] 聚焦画布检查、TypeScript、lint、build、Trellis baseline、本地重启及桌面/移动端模拟浏览器检查通过，且验证不调用付费服务或飞书生产写入。

## Out Of Scope

- 工作流导入导出、键位自定义、跨刷新或跨工作流持久化撤销历史。
- 修改任务队列、节点执行器、数据库结构或第三方服务调用协议。
- 在基线验证中执行真实付费模型或外部发布。
