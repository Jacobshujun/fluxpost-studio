# 修复图片预览鼠标中心缩放

## Goal

修复无限画布图片预览的滚轮缩放，使图片以鼠标当前所在位置为缩放中心，用户放大后能直接查看所指区域。

## Background

- `/canvas` 图片预览由 `src/app/canvas/page.tsx` 中的 `CanvasImagePreviewBody` 实现。
- 预览舞台通过非 passive 原生 `wheel` 监听器独占滚轮并更新 `zoom`，但当前不会根据鼠标位置同步调整 `scrollLeft` / `scrollTop`。
- 放大后的预览通过可滚动画布和现有左键拖拽查看局部；底层 React Flow 画布使用独立的原生缩放路径。

## Requirements

- 鼠标滚轮改变预览缩放时，缩放前位于鼠标下方的图片内容在缩放后应尽量保持在同一屏幕坐标；计算需同时覆盖水平和垂直方向。
- 锚点应使用鼠标相对于预览舞台可视区域的位置，并基于实际缩放前后的内容尺寸调整滚动偏移，避免把页面坐标或视口坐标直接当作内容坐标。
- 缩放到无溢出的范围时允许浏览器按滚动边界夹紧偏移；达到最小或最大缩放值时不得产生额外位移。
- 保留现有 `0.5` 至 `4` 的缩放范围、`0.25` 步长、工具栏缩放/重置、左键拖拽、中键自动滚动屏蔽、序列导航、键盘控制和焦点恢复。
- 不修改底层 React Flow 画布缩放/平移、API、持久化数据、运行队列或外部服务行为。

## Acceptance Criteria

- [x] 在预览图片已放大且可滚动的状态下，将鼠标放在舞台中心以外的位置滚轮放大或缩小，鼠标下方的同一内容点在缩放前后保持相同屏幕位置，允许亚像素/取整误差。
- [x] 连续滚轮缩放使用每次事件对应的最新缩放和滚动状态，不因 React 状态批处理产生锚点漂移。
- [x] 到达 `50%` 或 `400%` 边界后继续滚轮不会改变缩放或滚动位置；缩小到无溢出时偏移被正常夹紧。
- [x] 现有左键拖拽、中键屏蔽、工具栏控制以及关闭预览后的 React Flow 滚轮缩放保持正常。
- [x] 聚焦浏览器回归、TypeScript、变更文件 ESLint、生产构建、本地生产重启和 Trellis 全量基线通过，且不调用外部付费服务或写入飞书。

## Out Of Scope

- 改变工具栏按钮的中心缩放语义；工具栏仍按现有居中/浏览器滚动边界行为工作。
- 改变预览缩放范围、步长、动画、布局或拖拽手势。
- 修改 React Flow 的缩放算法或部署生产环境。
