# Gemini Canvas design

- Add model.gemini v1 to existing registration, executor and iteration allow-list. Reuse generic inspector fields, result rendering, serializer and DAG/scheduler stores. Instruction plus ordered prompt values form one user text part; optional images follow in order. No bypass of image inputs; bypass only copies prompt to text.
- A server-only Gemini module snapshots appConfig, validates the effective model, obtains ordered bytes using existing runtime materialization or owner-checked local directory snapshots, validates byte signatures and encodes inlineData. No Files API, image conversion, fallback provider, streaming, web tools or conversation state.
- Endpoint is GEMINI_BASE_URL/models/{model}:generateContent; base defaults to Google /v1beta. Send x-goog-api-key header, one user contents entry and TEXT response modality. Parse first candidate's non-thought text parts; reject blocked/truncated/non-text/empty results explicitly.
- Add six allow-listed advanced config keys: GEMINI_API_KEY, GEMINI_BASE_URL, GEMINI_MODEL, GEMINI_PROXY_ENABLED, GEMINI_PROXY_URL, GEMINI_REQUEST_TIMEOUT_MS. Default model empty, proxy off/address http://127.0.0.1:10808, timeout 180000. Validate URL/model/proxy/timeout before saving; retain existing global-in-place config synchronization. Node config never contains credentials.
- Use undici ProxyAgent for Gemini only, per-request dispatcher lifetime for safe concurrent configuration changes; close after response or cancellation. Use shared gpt concurrency with AbortSignal. A composed deadline covers the whole operation, including local/remote reads, queue and body. Requests do not retry automatically.
- Limits: 8 images, 7*1024*1024 bytes each, JPEG/PNG/WebP verified from bytes, 20,000,000 UTF-8 bytes for serialized JSON. Materialization cleanup in finally. No raw provider error payloads in messages/logs; expose bounded status/category guidance only.
- Activation reuses primary-worktree managed build slots and npm run local:lan, after clean commit and read-only queue-drain check. Do not cancel operator work or mutate runtime config/data. Offline acceptance is sufficient for code delivery; live Gemini acceptance remains pending.
