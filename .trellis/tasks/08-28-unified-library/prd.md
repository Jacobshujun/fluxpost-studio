# 统一图库与高性能资源管理

## Goal

将固定的“参考图库 / 车型库”改造成统一图片资产池，以普通图集、扁平标签、收藏、备注和智能文件夹组织素材，并让图库在 5 万张图片规模下保持稳定分页和可用响应速度。Canvas、简单模式和历史配置必须迁移到图集或规则来源，运行时继续冻结资产快照。

## Background

- 当前资产通过 `roles: reference | vehicle` 分库，图集也绑定角色；实际库有 621 张图片、2,769 条标签、6 个图集，且没有双角色资产。
- 当前列表查询每次加载全部资产 JSON 后在 Node.js 过滤、排序和分页；图库网格仍直接加载 TOS 原图。
- 现有结构化 AI 标签、人工覆盖、TOS 存储、缩略图服务、游标分页、权限和 Canvas 快照能力必须保留。

## Requirements

### Unified model and migration

- 活动模型和公开 API 删除 `LibraryAssetRole`、资产 `roles/roleAddedAt`、图集 `role` 和 `role` 查询参数。
- 图集为普通嵌套文件夹，具有个人/团队可见性。资产可属于 0-N 个图集；系统视图包括全部、未分类和收藏。
- 父图集默认包含所有后代图集资产并去重，同时支持仅直接成员。
- 删除图集只删除该图集关系并把直接子图集上移；不得删除图片。
- 一次性迁移为每个旧角色生成稳定普通根图集“参考图库”“车型库”，保留现有图集层级并加入旧角色资产。
- 历史 Canvas/V2/简单模式配置中的旧角色改写为迁移根图集 ID；不保留公开双轨兼容。
- 新导入图片不自动创建 AI 打标任务；单图、批量和失败重试均由用户手动触发。

### Ownership and organization

- 图集和智能文件夹支持个人/团队可见；团队成员只读，所有者和管理员可管理。
- 可见的团队共享图片可加入当前用户拥有的个人图集，而不改变图片本身。
- 收藏按用户独立存储；备注属于图片元数据，仅图片所有者或管理员编辑。
- 标签继续保留结构化 AI 维度和人工覆盖，前端统一扁平展示，并支持自动补全、批量增删、重命名和合并。

### Smart folders

- 智能文件夹持久化名称、所有者、可见性、`all | any` 和一层结构化条件。
- 条件支持标签包含/不包含、图集、名称/原始名/备注、所有者、共享范围、图片类型、尺寸、文件大小、入库时间、打标状态和当前用户收藏。
- 不支持嵌套条件组、评分、颜色标记、标签组或层级标签。

### Query and bulk behavior

- 权限、搜索、图集子树、收藏、智能文件夹、标签、结构化维度、排序和 keyset 分页必须在数据库侧执行，禁止读取全库后在 Node.js 过滤。
- 默认页大小 60，最大 100；游标绑定筛选和排序签名。
- 资产列表返回紧凑卡片数据和缩略图 URL；图集、智能文件夹和侧栏计数单独加载。
- 同一维度多值为 OR；跨维度及重复统一标签为 AND。
- 全选采用服务端“全部匹配 + 排除 ID”选择快照，批量标签、图集、可见性、收藏和删除不得把所有结果拉入浏览器。

### UI and consumers

- `/library` 删除双图库标签页，改为系统视图、普通图集和智能文件夹侧栏。
- 导入不再提交角色，可选 0-N 个目标图集；卡片和预览缩略条使用缩略图 API，预览主图使用原图。
- 保留导入、粘贴、拖拽、分页、框选、键盘、预览、标签和权限反馈，并支持搜索防抖与过期请求取消。
- Canvas 和简单模式支持普通图集、智能文件夹和临时筛选；启动前验证访问权限并冻结资产快照。
- 已启动任务不受后续图集、规则、标签或源资产变化影响。

## Acceptance Criteria

- [x] PostgreSQL、SQLite、新安装 schema 和增量迁移均覆盖统一资产、图集、智能文件夹、收藏、标签和查询索引。
- [x] 当前旧角色和图集可无损迁移，历史 Canvas/简单模式配置不再依赖角色且仍可运行。
- [x] 图集层级、子树汇总、直接成员、未分类、共享只读、个人整理和删除上移语义通过确定性检查。
- [x] 智能文件夹 `all/any`、全部条件类型、权限和收藏用户语义通过检查。
- [x] 数据库查询覆盖权限、搜索、AND/OR 标签、稳定游标、排序和侧栏元数据，不再调用全库资产读取完成列表。
- [x] 服务端查询选择支持全部匹配、排除项、部分失败和永久删除确认语义。
- [x] 新导入不自动打标，手动单图/批量/重试保留人工覆盖。
- [x] `/library` 桌面 1440x960 和移动 390x844 可完成核心工作流，无水平溢出，卡片不加载 TOS 原图。
- [x] Canvas、简单模式和其他图库消费者使用统一来源并保持冻结快照契约。
- [x] 隔离 PostgreSQL 50,000 张、约 1,000,000 标签关系基准中常用列表查询 P95 < 300ms，首屏元数据 P95 < 500ms。
- [x] 聚焦检查、TypeScript、lint、build 和完整离线 baseline 通过，不调用付费或生产外部服务。

## Out Of Scope

- Eagle 服务集成、语义向量检索、人脸识别、评分、颜色标记和嵌套查询表达式。
- 修改 TOS 对象存储策略或已启动任务的冻结数据。
- 用户可见的旧/新图库双轨灰度。
