# 批量创作向导

## Goal
普通同事通过独立 /batch-create 四步向导使用完整 V2 灵活调度；原画布 V1/V2 调度保持可用。

## Confirmed requirements
用户已批准计划并要求实施。首页入口；选择工作流、填写素材、设置生成方式、预览启动；任务记录及全部既有运行操作；共享后端任务，无新引擎/表。所有输入类型、内层绑定、Excel、共享输出、随机范围、文本分隔方式往返无损。保存冲突和预览失效明确展示；不能静默选择歧义绑定。保留权限；不新增跨用户共享、定时、AI配置或发布行为。

## Acceptance
- 四步创建、保存恢复、预览修改、启动与结果/失败处理可独立完成。
- V2 配置往返保真；V1 原入口定位；新旧页面定位同一记录。
- 冲突、重复点击、失效绑定、过期预览、空素材、网络错误可见。
- 三主题及1440/390布局、键盘、长文案可用。
- 原调度回归、隔离浏览器验证、完整baseline通过；无真实模型/飞书调用。
- 验证提交后使用主工作区正常本地入口激活3001，不部署远程。
