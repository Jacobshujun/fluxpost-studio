# Product

## Register
product

## Users and purpose
FluxPost Studio serves a small team of signed-in content operators. This task adds a guided batch creation page for colleagues unfamiliar with node-based scheduling. Users select an existing workflow, supply content and media, configure combinations, preview the real task expansion, and inspect generated results. The user explicitly selected guided free configuration with full capability and progressive disclosure.

## Principles
Clear, calm, practical Chinese labels. Preserve the existing application themes and account boundaries. Prefer familiar forms and a four-step wizard with a persistent summary. Avoid technical identifiers in the default flow, decorative marketing sections, and a second execution system. Keep advanced options accessible without hiding active settings. Keyboard access, visible focus and narrow-screen operation are required.
