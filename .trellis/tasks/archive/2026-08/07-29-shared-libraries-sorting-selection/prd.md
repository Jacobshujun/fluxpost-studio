# 共享资料库排序与框选

## Goal

让本地应用中的图片素材库和文案库默认面向团队共享，并让用户能按常用规则排序、通过鼠标拖动框选批量选择条目，从而减少逐项修改与选择的操作成本。

## Background

- 用户明确要求图片素材库、文案库新建内容默认团队共享。
- 用户明确要求图片素材库、文案库支持多种排序方式。
- 用户明确要求图片素材库、文案库支持鼠标拖动批量选择。
- 图片库已有复选框多选及批量共享范围、标签、重新打标、移出和删除操作；文案库目前只有单选编辑和单条删除。
- 图片库当前按 `createdAt` 降序并使用游标分页，文案库当前按 `updatedAt` 降序；多排序必须由各自领域/API 合同执行，不能只重排客户端已加载数据。
- 图片导入的客户端与服务端缺省可见性目前都是 `private`；文案新建草稿与服务端缺省可见性目前也是 `private`。

## Requirements

### R1. Default Team Visibility

- 图片素材库正常导入的新条目默认使用团队可见性。
- 文案库新建条目默认使用团队可见性。
- API 调用方仍可显式传入 `private`；不得自动改变已有私有条目，历史素材迁移也不得因缺省值变化而改写原有私有语义。

### R2. Stable Sort Options

- 图片库排序项为最新导入、最早导入、名称 A-Z、名称 Z-A、提交人 A-Z、提交人 Z-A；默认最新导入。
- 文案库排序项为最近更新、最早更新、标题 A-Z、标题 Z-A、提交人 A-Z、提交人 Z-A；默认最近更新。
- 提交人使用现有 `ownerDisplayName`，文本按 `zh-CN` 规则比较，并使用记录 ID 作为稳定的最终决胜字段。
- 图片库排序必须覆盖完整筛选结果和游标分页，不能只重排客户端已加载数据。
- 两库分别将排序偏好保存在浏览器本地；首次访问或无效存储值回落到各自的最新优先默认值。

### R3. Desktop Marquee Selection

- 两个资料库都允许桌面鼠标从列表/网格空白区域开始拖动选择框，一次选择多个可见条目。
- 普通框选用框内条目替换当前选择；按住 `Ctrl` 或 `Cmd` 框选时把框内条目追加到当前选择。
- 框选不得抢占预览、编辑、复选框等条目内控件；移动端继续使用点击复选路径。
- 筛选、排序、角色或分页结果变化后，不可见条目不得残留为可操作选择。

### R4. Copy Batch Actions And Permissions

- 文案库提供独立于当前编辑条目的批量选择状态，并支持批量设为团队共享、批量设为仅自己和批量删除。
- 批量删除必须二次确认；批量结果应明确显示成功数与失败数。
- 团队共享条目仍只有所有者或管理员可修改、删除；普通成员选中只读条目时，服务端鉴权失败必须被计入结果而不能静默越权。

### R5. Copy Library Selection Shortcuts

- 文案库提供始终可见的全选入口，并保持批量选择与当前编辑文案相互独立。
- 桌面端支持 `Ctrl`/`Cmd` 点击切换单项、`Shift` 点击连续范围选择，以及 `Ctrl`/`Cmd` + `Shift` 点击追加连续范围。
- 非编辑区域支持 `Ctrl`/`Cmd+A` 全选当前筛选结果、`Esc` 取消选择、`Delete` 打开批量删除确认。
- 全局快捷键不得拦截输入框、文本域、下拉框、可编辑区域或已打开弹窗中的原生键盘行为。

### R6. Fixed Copy Library Workspace

- 桌面端文案库页头与右侧编辑工作区固定在视口内，滚动左侧文案时仅左侧列表移动。
- 左侧筛选、全选和批量操作区域保留在列表上方；右侧长内容在编辑区内部滚动，不产生文档级滚动。
- 移动端列表占满页头以下空间并保持内部滚动，编辑器覆盖层和返回列表行为保持不变。

## Acceptance Criteria

- [ ] AC1: 不显式选择可见性时，新图片素材和新文案均保存为 `team`；显式 `private` 仍生效，已有记录与历史迁移不被隐式改写。（R1）
- [ ] AC2: 两库均显示已确认的六种排序项，默认最新优先，刷新页面后恢复各自上次有效选择。（R2）
- [ ] AC3: 每种排序都使用稳定决胜字段；图片库跨游标加载后无重复、漏项或顺序跳变。（R2）
- [ ] AC4: 桌面端从空白区域普通拖动会替换选择，`Ctrl`/`Cmd` 拖动会追加选择，选择框视觉范围与命中条目一致。（R3）
- [ ] AC5: 条目内预览、编辑和复选框保持原行为；移动端仍可通过点击复选完成多选。（R3）
- [ ] AC6: 筛选、排序、图片角色或数据刷新后，批量选择只包含当前可见条目。（R3）
- [ ] AC7: 文案批量共享范围修改与批量删除汇总成功/失败；删除有二次确认，只读团队文案不能被普通成员修改或删除。（R4）
- [ ] AC8: 新增或更新的确定性检查覆盖默认可见性、六种排序、游标合同、框选核心逻辑和权限；FluxPost Trellis 基线通过且不调用外部生产服务。（R1-R4）
- [x] AC9: 文案库可通过可见全选控件、`Ctrl`/`Cmd` 点击、`Shift` 连选和常用键盘命令管理批量选择，编辑控件与弹窗不被全局快捷键截获。（R5）
- [x] AC10: 鼠标滚动左侧文案列表时，文档滚动位置、页头和右侧编辑区位置保持不变；桌面与移动端均无横向溢出。（R6）

## Out Of Scope

- 自动改变历史私有条目的可见性。
- 放宽团队共享条目的编辑、删除权限。
- 为移动端新增触控拖拽框选。
- 自动滚动式超长距离框选或拖动条目重新排序。
- 将个人排序偏好同步到服务端或其他用户。
