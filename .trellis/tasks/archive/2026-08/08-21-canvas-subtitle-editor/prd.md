# Canvas 字幕人工校对编辑器

## Goal

为 `utility.video-subtitles@1` 增加可复现、按所有者隔离的人工校对流程。字幕节点首次成功识别后，用户可以在画布内全屏编辑器中结合视频、字幕覆盖层、波形与时间轴修正文字和时间；只有显式“应用并重新生成”才保存节点快照并单独重新烧录该字幕节点。

## Requirements

- 保持现有 `videos`、`text` 输出端口和节点版本不变。
- 新成功运行内部保存视频 SHA-256、时长、协议版本和已验证字幕段；旧运行没有这些信息时提示重新运行。
- 修订稿按所有者、工作流、节点和视频 SHA-256 隔离，保留原始识别稿与最新人工稿，使用递增 `revision` 乐观锁。
- 编辑器支持文本和毫秒级时间修改、拖动/缩放/滚动时间轴、播放游标、当前段高亮、字幕覆盖、新增、删除、拆分、合并、本地撤销/重做和恢复识别稿。
- 服务端生成并缓存 8 kHz 单声道、每秒 50 组 min/max 峰值的音频波形；FFmpeg 使用现有 `localVideo` 并发池。
- 草稿仅在显式保存时持久化；关闭脏编辑器必须确认。
- “应用并重新生成”先保存修订稿，再用工作流 revision 保存不可变字幕快照，最后创建当前字幕节点 isolated run。
- 视频哈希匹配时执行器使用冻结快照并跳过 Whisper；哈希不匹配时忽略快照并按正常识别流程运行。
- isolated run 复用上游成功视频，不执行下游节点；批量调度只消费节点配置中冻结的快照。
- 工作流删除时清理其字幕修订；工作流复制/导入导出/运行快照保持配置快照可复现。
- 所有 API 要求登录，普通成员只访问自己数据，管理员可访问所有者范围内记录。

## Validation Rules

- 字幕段数量 1 到 1000。
- 每段文字 trim 后 1 到 500 个字符。
- 时间为整数毫秒，满足 `0 <= startMs < endMs <= durationMs`。
- 字幕段严格按开始时间排序且不重叠；允许间隙。
- 拖动精度 10ms，并钳制在视频和相邻段边界内。
- 拆分要求播放点位于当前段内部，文字光标位于文本内部。
- 合并取首段开始和次段结束，并按中英文边界智能拼接文本。

## Acceptance Criteria

- [x] 成功运行具备内部结构化时间轴，旧成功运行显示可操作的重新运行提示。
- [x] 修订 CRUD、所有者/管理员访问、409 冲突、节点隔离、视频哈希隔离与删除清理可验证。
- [x] 编辑器完成计划中的桌面/移动端交互，字幕、视频、波形和时间轴同步，无横向页面溢出。
- [x] 匹配快照只执行 FFmpeg 烧录且零 Whisper 调用；错配哈希绝不复用人工稿。
- [x] 波形生成、缓存复用、并发去重、超时和无音轨错误均有确定性测试。
- [x] Canvas 字幕、工作流、调度、TypeScript、lint、build 与完整离线 Trellis baseline 通过。
- [x] 改动提交后由 `npm run local` 激活，并验证端口 3001 的完整 SHA 与 `/canvas` 健康。

## Out Of Scope

- OCR、内嵌字幕导入、软字幕、翻译、自动保存和完整修订历史。
- 编辑时自动编码、隐式运行下游模型或发布节点。
- 对缺少结构化时间轴的历史成功运行进行推测性迁移。
