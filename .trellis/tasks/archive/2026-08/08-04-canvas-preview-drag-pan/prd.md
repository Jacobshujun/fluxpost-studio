# Canvas 图片预览左键拖动

## Goal

让用户在无限画布的图片预览中放大图片后，可以按住鼠标左键拖动查看局部，而不依赖水平或垂直滚动条。

## Background

- `/canvas` 图片预览由 `src/app/canvas/page.tsx` 中的 `CanvasImagePreviewBody` 实现。
- 预览舞台是 `overflow: auto` 滚动容器；滚轮已由非 passive 监听器独占为预览缩放，中键默认自动滚动已被禁用。
- 放大后的图片通过现有画布尺寸产生可滚动区域，拖动可以直接更新舞台的 `scrollLeft` 和 `scrollTop`。

## Requirements

- 在预览舞台存在水平或垂直溢出时，鼠标左键按住并拖动可平移可见区域。
- 使用指针捕获保持连续拖动；指针移出舞台后，在松开前仍可继续平移。
- 仅接管鼠标左键。触摸设备保留浏览器原生滚动/滑动行为，中键继续禁止 Chromium 自动滚动。
- 拖动过程中使用明确的抓取光标反馈，结束或取消拖动后恢复。
- 保留现有滚轮缩放、缩放范围与步长、滚动条、页头/页脚控件、序列导航、键盘控制和焦点恢复。
- 不改变底层 React Flow 画布手势、API、持久化数据或外部服务行为。
- 将通过本地和隔离候选验证的精确完整 SHA 部署到生产 `38.76.210.136`，不改变生产配置、数据或命名卷。

## Acceptance Criteria

- [x] 图片放大并产生溢出后，从预览舞台内左键拖动会按拖动距离更新 `scrollLeft`/`scrollTop`，从而查看图片局部。
- [x] 指针拖出预览舞台边缘后仍可继续平移，松开或取消指针会立即结束拖动状态。
- [x] 未产生溢出时左键拖动不会移动内容；触摸滑动不被新的鼠标拖动逻辑接管。
- [x] 滚轮缩放仍不改变已有滚动偏移，中键移动仍不触发自动滚动，页头/页脚控件仍可正常点击。
- [x] 关闭预览后，底层无限画布的缩放行为保持正常。
- [x] 聚焦浏览器回归、TypeScript、变更文件 ESLint、生产构建、本地重启和 Trellis 全量基线通过，且不调用付费服务或写入飞书。
- [x] 精确候选 SHA 通过 VPS 隔离验证和只读预检后部署到生产 38；发布身份、`/canvas`、API 鉴权边界、服务健康和持久卷检查通过。

## Out Of Scope

- 增加空格键加左键的第二套拖动模式。
- 改变无限画布的缩放曲线、平移按键或移动端手势。
- 调用图像/文本供应商或写入飞书。
