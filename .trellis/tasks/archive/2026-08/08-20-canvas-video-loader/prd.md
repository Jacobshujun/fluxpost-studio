# Canvas 视频加载节点

## Goal

在无限画布增加独立的本地“视频加载”节点：一次可选择或拖入多个视频形成有序队列，普通运行只输出当前选中的一个视频，V2 批量调度按队列逐项冻结并为每个任务绑定一个视频。

## Background

- 现有 `input.videos@1` 只接受 URL，`input.source-video@1` 负责解析平台链接；两者保持不变。
- Canvas 已有 `videos` artifact、视频预览、运行时媒体存储、FFprobe/FFmpeg 和 V2 参数调度能力。
- `/api/canvas/media` 只支持图片，现有 `source-video` 调度参数依赖内容池快照，不能表达本地上传队列。

## Requirements

- R1. 注册独立 `input.video-loader@1`，配置保存最多 200 个有序视频快照与 `selectedVideoId`；首个成功项自动选中。
- R2. 视频快照保存稳定 ID、原文件名、URL、MIME、字节数、时长、宽高、音轨状态和上传时间；工作流只保存 URL/元数据，不保存二进制或 Base64。
- R3. 接受 MP4、MOV、WebM，单文件最大 512 MB；服务端流式写入、同步计算 SHA-256，并用 FFprobe 验证真实容器和视频流。
- R4. `POST /api/canvas/video-uploads?filename=...` 需要登录，每次接收一个原始文件体；成功媒体以内容哈希命名并通过运行时媒体存储持久化，失败或取消清理临时文件。
- R5. 浏览器顺序上传多个文件并显示逐项字节进度；单项失败不阻断其余项，支持单项重试。相同内容在同一队列中去重。
- R6. 节点检查器支持选择、追加、当前项单选、视频预览、移除和排序；桌面拖到空白画布创建节点，拖到已有加载节点追加；移动端可在检查器管理队列。
- R7. 节点本体只渲染当前视频摘要、预览命令和队列计数，不挂载整列视频元素。
- R8. 普通运行严格输出当前项对应的单条 `videos` artifact；空队列、失效选择或非法快照在图校验阶段失败。
- R9. V2 调度增加 `video` 参数、`video-loader-queue` 来源和绑定适配器；预演从绑定节点读取有序队列并冻结快照，运行图中每个任务只保留被绑定的一个视频。
- R10. 视频参数默认 `each` 展开，可属于主/子任务并沿用现有 Cartesian、zip 和并发行为；预演后编辑节点不得改变已冻结批次。
- R11. 移除队列项只删除画布引用，不删除底层媒体；不增加内容池写入、共享素材库、转码、裁剪、压缩或封面生成。

## Acceptance Criteria

- [x] AC1. 登录用户可从文件选择器或桌面拖放批量加载 MP4/MOV/WebM，成功与失败项分别显示且可重试。
- [x] AC2. 上传入口拒绝空文件、伪装或不支持格式、无视频流和超过 512 MB 的输入，并清理临时文件。
- [x] AC3. 节点最多保留 200 个去重快照，可排序、移除、预览和切换当前项，工作流保存/导入/导出后保持一致。
- [x] AC4. 普通运行只输出当前视频；字幕、抽帧和 Seedance 等现有 `videos` 下游继续通过端口兼容性连接并执行自己的限制。
- [x] AC5. V2 调度可把队列逐项展开，每个任务冻结一个视频；后续节点编辑不改变已预演批次。
- [x] AC6. 历史 `input.videos@1` 与 `input.source-video@1` 工作流无需迁移且继续可用。
- [x] AC7. 聚焦契约、上传服务、调度、桌面/移动端浏览器检查，以及 TypeScript、lint、build 和完整离线基线通过，不调用外部付费服务。

## Out Of Scope

- 视频转码、剪辑、压缩、封面生成、共享视频素材库、内容池导入和新增调度并发设置。
- 自动删除未再引用的运行时媒体或生产部署。
