# Canvas 展示任何节点

## Goal

在无限画布中增加一个名为“展示任何”的只读预览节点，让操作者可以把任意现有节点的输出接入同一个节点，并直接查看该输出内容，无需依赖底部运行记录。

## Background

- Canvas 当前用 `CanvasArtifact` 表示五类输出：文字、图片、视频、社交内容和发布任务引用。
- 现有端口的 `kind` 只能是单一 `CanvasArtifactKind`，图校验和快速插入都按类型完全一致匹配。
- 现有节点内预览已分别覆盖文字、图片、视频、社交内容；发布任务引用当前只在通用运行结果中展示。
- `utility.image-preview` 是图片专用预览节点，并具有图片透传输出；新节点不能改变它或既有工作流的行为。

## Requirements

- 注册一个版本化的 `utility.display-any` 节点，中文名称为“展示任何”，归入工具节点。
- 节点使用单个通配输入端口；该端口可连接任一现有产物类型，但一次只允许一条上游连线。
- 节点是纯终点预览，不声明输出端口；需要继续处理时，操作者从原上游节点分叉连线。
- 当操作者运行上游节点或“运行到此节点”时，系统自动把与目标直连的“展示任何”节点纳入本次运行并刷新结果。
- 节点只读取并展示上游运行产物，不调用模型、外部写入或其他生产服务。
- 节点能展示 `text`、`images`、`videos`、`socialPost` 和 `publishJobRef` 五类现有产物。
- 展示内容使用现有 Canvas 预览交互：长文字可打开全文，图片可打开图片查看器，视频可播放并打开大图层；社交内容和发布任务显示可扫描的关键字段。
- 当前运行无可展示产物时显示明确状态；当前运行失败、阻塞、等待配置或运行中时显示对应状态。
- 当前选择运行没有成功产物时，可回退显示该节点最近一次成功结果，并标注工作流版本与时间，遵循现有节点结果规则。
- 节点保存、复制粘贴、图校验、运行快照、执行、结果复用、重试和旧工作流加载均保持兼容。
- 桌面端支持从节点面板、搜索和兼容连线快捷插入；移动端保持可查看且无水平溢出。
- 通配规则只用于“展示任何”的输入端口；既有类型化输出与类型化输入之间仍要求种类完全一致。

## Acceptance Criteria

- [ ] “展示任何”可在节点面板和搜索中找到，并能保存到工作流后重新加载。
- [ ] 所有五类现有输出均能合法连接并执行，错误类型或无效端口仍被图校验拒绝。
- [ ] 从任一类型化输出拖出连线时，“展示任何”出现在兼容节点搜索中；从“展示任何”的空输入反向拖线时，所有类型化输出节点都可被选择。
- [ ] 每次执行准确展示接入的上游产物，不把上一次或其他端口的数据误认为当前结果。
- [ ] 文字、图片、视频、社交内容和发布任务引用各有清晰、可操作且不溢出的展示。
- [ ] 运行中、失败、阻塞、等待配置、空输出、历史版本和最近成功回退状态均有明确反馈。
- [ ] 新节点不触发付费确认或外部写入，不改变现有节点定义、端口兼容和旧运行快照。
- [ ] 确定性 Canvas 检查、TypeScript、lint、build、Trellis baseline 及模拟桌面/移动浏览器检查通过，不调用外部生产服务。

## Out Of Scope

- 新增 `CanvasArtifact` 业务产物种类。
- 在预览节点内编辑或转换上游内容。
- 同时聚合多个上游输出或跨多次运行做对比。
- 从“展示任何”继续向下游透传动态类型输出。
- 替换现有图片预览、模型结果预览或底部运行记录。
