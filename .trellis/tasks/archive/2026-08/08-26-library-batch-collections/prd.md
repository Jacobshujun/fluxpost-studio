# 图库批量集合管理

## Goal

让参考图库和车型图库的操作员能够对当前选择的图片统一管理集合关系，减少逐张整理成本，同时保留现有角色、标签、可见性、对象存储和其他集合关系。

## Background

- `/library` 已支持框选、全选、批量标签、可见性、重新打标、移出当前视图和永久删除。
- `LibraryAsset.collectionIds` 已允许一张图片属于多个集合，现有 API 只提供逐张集合移出和逐张资产 PATCH。
- 普通成员只能编辑自己的资产和集合；团队共享资产可以只读查看和选择；管理员沿用现有工作区管理权限。

## Requirements

- 批量栏提供“管理集合”入口；集合面板使用层级复选列表，允许一次选择多个当前图库角色的目标集合，并可按名称或路径搜索。
- 每个目标集合显示选中图片中已有成员数量；全部已加入的集合保持可见但不重复写入。
- “加入集合”仅对现有 `collectionIds` 做并集，不移除任何原集合关系。
- 面板支持“新建并加入”：全部图片视图创建顶层集合，集合视图创建当前集合的子集合；同路径集合存在时复用。
- 集合视图支持批量移出当前集合；全部图片视图保留并明确标注原有“移出当前图库”角色移除能力。
- 批量写入期间禁用重复提交。加入成功后保留选择；移出当前集合后刷新列表并移除已不可见的选择。
- 结果反馈分别给出已更新、原本已归类、只读/无权限跳过及失败数量；单张失败不得阻断其他图片。
- 新增认证批量端点，目标集合必须先整体通过存在性、角色和所有权验证；无效目标在任何图片写入前返回 `400`。
- 输入资产和集合 ID 去重且不得静默截断。单资产权限、缺失、图库角色不匹配作为逐项失败返回。
- 不调用外部 TOS、AI、Feishu 或其他生产服务，不改变数据库结构或对象存储文件。

## Acceptance Criteria

- [x] 参考图库和车型图库均可将任意当前选择批量加入一个或多个有效集合，其他集合关系保持不变。
- [x] 已全部归类的目标不重复写入；混合选择显示准确的成员计数和 unchanged 数量。
- [x] 可在当前层级新建或复用集合并立即加入选中图片。
- [x] 当前集合中的批量移出只删除该集合关系；全部图片中的角色移出仍可用且文案明确。
- [x] 普通成员的只读团队图片产生逐项失败，自己的图片继续成功；管理员行为保持兼容。
- [x] 无效、错误角色或不可管理的目标集合在写入前使请求整体失败。
- [x] 桌面和移动端面板无水平溢出、控制裁切或重复提交，并能显示部分成功结果。
- [x] 图库 focused checks、类型检查、lint、生产构建和完整离线基线通过。

## Out Of Scope

- 集合重命名、删除、层级移动或跨图库角色迁移。
- 永久删除流程、对象存储、标签和 AI 打标流程重构。
- 数据库迁移、真实外部服务调用或生产部署。
