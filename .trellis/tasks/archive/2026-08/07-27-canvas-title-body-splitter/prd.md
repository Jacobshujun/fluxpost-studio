# Canvas 文本分割节点

## Goal

完善无限画布现有 `utility.text-split`，让操作者可把视觉模型生成的整段文案稳定拆成标题和正文，并直接检查两个输出。

## Background

- 当前 V1 节点名为“文本拆分”，支持第一行或第一次自定义分隔符，输出内部端口 `head` 和 `tail`。
- 当前 V1 在缺少分隔符或任一侧为空时失败，且节点只预览第一个文本输出。
- 用户确认节点显示名称为“文本分割”，并要求自定义第 N 个分隔符、节点内快捷配置和双结果预览。

## Requirements

- 保持节点类型 `utility.text-split`、输入端口 `text`、输出端口 ID `head`/`tail` 不变；V2 的输出标签为“标题”和“正文”。
- V2 支持 `first-line` 和 `delimiter` 两种模式。自定义模式使用精确、区分大小写、互不重叠的文本匹配。
- V2 配置增加从 1 开始的正整数 `delimiterIndex`，默认值为 `1`；默认分隔符继续为 `---`。
- 第 N 个分隔符是标题与正文的边界。例如 `A---B---C` 使用第 2 个 `---` 时得到标题 `A---B`、正文 `C`。
- 移除边界分隔符并分别 trim 标题与正文，保留正文内部空白和段落。
- 找不到指定边界或任一侧为空时，V2 成功输出完整原文为正文且不输出标题；完全空白的输入仍明确失败。
- 新节点使用 V2；可编辑 V1 节点在正常保存或复制时升级。V1 注册定义和严格执行语义继续支持历史快照。
- 节点内部与右侧属性面板都可编辑模式、分隔符和序号，且使用同一份配置。
- 节点结果分别展示标题和正文并支持完整文本预览；降级结果明确显示“未匹配，已全部作为正文”。
- 保持桌面节点缩放和移动端布局稳定，不引入水平溢出。

## Acceptance Criteria

- [ ] 新建“文本分割”节点使用 V2，端口 ID 保持兼容，V1 定义和历史语义仍可解析执行。
- [ ] 第一行和第 N 个自定义分隔符都按已确认规则输出标题/正文。
- [ ] 未匹配或空侧结果只输出完整正文，不向下游传递空标题；空输入失败。
- [ ] 节点内控件和属性面板同步，第一行模式隐藏分隔符相关配置。
- [ ] 标题、正文及降级状态都可在节点结果中辨认和完整预览。
- [ ] 工作流保存、复制、剪贴板、不可变快照与结果复用继续使用现有接口和持久化形状。
- [ ] 确定性检查、TypeScript、lint、build、完整 Trellis baseline、本地生产重启和桌面/移动端模拟检查通过，不调用付费服务。

## Out Of Scope

- 正则表达式、忽略大小写或重叠匹配。
- 任意数量输出的通用列表分割器。
- 视觉模型提示词、模型调用、外部服务、API 或数据库变更。
