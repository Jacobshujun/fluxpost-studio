# FluxPost Studio 更新说明

## 2026-10-22 GitHub 同步

本次同步 `1298237` 之后的 89 个本地提交，覆盖 2026-09-15 至 2026-10-22 的功能、修复、验证与任务记录。范围包含 31 个功能/修复提交和 58 个文档、验证与任务记录提交；共变更 424 个文件，新增 14,616 行、删除 1,378 行。

### Canvas 工作流与媒体处理

- 新增图片处理节点：支持批量压缩、等比缩放、裁切、填充、格式转换和前后效果对比；目标无法满足时明确失败，不偷偷降低尺寸或画质。(`1283867`, `5716cab`)
- 新增图层合成节点：支持最多 24 个图片、视频和纯色图层，保留几何、顺序、透明度和音量设置，并输出 PNG 或 MP4。(`9369fc7`, `a864929`, `f14c141`)
- 新增逐图迭代共享参考图的 1-16 号输入端口，参考图按端口顺序排列；旧版参考连接继续兼容，原有 GPT-Image-2 行为不变。(`6d43165`)
- Canvas 图片可自动保存到指定本地文件夹，保留原始字节和扩展名，遇到同名文件自动编号，不覆盖已有文件。(`70cb543`)
- 新增 Gemini 原生文字与视觉节点，支持有序图片输入、独立模型和代理配置、请求取消及普通、V2、迭代工作流。(`5ca173a`)
- 新增显式 CPU/NVIDIA H.264 编码选择，视频重建、幻灯片、遮罩、图层合成和字幕烧录共用同一编码策略；配置硬件不受支持时明确报错。(`b722ce3`)
- 修复批量任务取消后仍显示运行中、图片处理长期占用执行槽的问题；补上过期租约、取消意图和下游启动的持久化保护。(`52c8c00`)
- 新增画布节点分组、Shift 多选、复制粘贴和 Ctrl/Cmd+G/B/M 快捷键；分组信息会随工作流保存、复制和导入。(`126a3af`)
- 从左侧节点库添加节点时，改为按当前画布缩放和移动后的鼠标位置放置；空画布添加首个节点时不再跳动视图。(`46f6783`)
- 新增透明背景模板遮罩、Smart Folder 图片选择和图层重跑源绑定；修复合成输出在 TOS 持久化后无法读取哈希的问题。(`a617c61`, `ead8ee4`, `9f17c8e`, `5c3f07f`)
- 新增节点自带的图片模型、画质、比例、分辨率和背景设置；普通版与 Official ToAPIs 请求按各自协议发送。(`2735c20`, `027bec0`, `a0e77fc`)

### 图片生成与简单模式

- 简单模式支持压缩、格式、尺寸和画质配置，可在生成后统一处理图片；设置会随任务冻结，恢复任务不会重新读取后来修改的配置。(`b9107a1`)
- 简单模式与 Canvas 共用图片模型和请求参数，并支持保存、恢复默认值和非法配置校验。(`a9f878f`)

### 素材库与采集

- 图片库新增按搜索、标签、尺寸、日期、可见性和汽车属性组合筛选；筛选条件会写入 URL，支持刷新、前进后退和分页。(`3147e19`)
- 图片库新增原图查看、缩放平移、单张详情、独立选择、批量标签、图集搜索和串行导入回执；删除操作保留确认，避免误删。(`3147e19`, `9dba663`)
- 图片库接入主色预览和颜色筛选，最多展示六种主色；新增图片的本地颜色分析可重试，并保持原有筛选条件和冻结结果有效。(`65146eb`)
- 小鹏社区采集修复正文和正文内图片丢失；后续修复了正文中视频插入导致的导入失败，并保留视频前后的文字与图片。(`a9b0edd`, `3af5e48`)
- 修复懂车帝采集失败提示不清晰、拆分音轨视频被误收的问题。(`42b2910`, `fec50a8`)

### 配置、可靠性与其他修复

- 新增全局文本推理强度配置：支持 `default`、`none`、`minimal`、`low`、`medium`、`high`、`xhigh`、`max`，并覆盖所有 OpenAI 兼容文本请求；Gemini 和媒体生成不受影响。(`9eef8ed`)
- Canvas 检查器只为当前选中的节点显示；GPT 图片保留五档画质；图片模型选择器可以独立保存每个节点的设置。(`5918c73`, `fec7c13`)
- 新增本地 API 面板安装记录和 FRP/LAN 启动说明；Windows 快捷方式复用受保护的 `npm run local:lan` 启动链路，动态 FRP 面板需通过密码和 SSH/HTTPS 管理入口访问。(`4e43de8`, `e281aac`, `48b06f0`, `ff0c361`)
- 增加 Canvas 取消恢复工具和图像 API 本地诊断能力，便于在任务卡住时只恢复受影响的记录。(`52c8c00`, `dbb76a2`, `eb79c4b`)
