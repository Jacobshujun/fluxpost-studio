# FluxPost Studio 更新说明

## 2026-11-16 GitHub 同步

本次整理上次 GitHub 同步点 `a7397e2` 之后、截至 `1e12fe8` 的 78 个本地提交，覆盖 2026-11-03 至 2026-11-16 的功能、修复、验证与任务记录。该范围共变更 419 个文件，新增 16,320 行、删除 2,483 行；本说明及本次同步记录另计。

### 批量创建、历史复用与失败恢复

- 新增四步批量创建页面，集中完成输入配置、执行预览、启动和结果查看，继续使用原有批量调度器。输入支持手动列表、Excel、迭代内部参数和共享参数，保留已有输入内容。(`c05af9b`)
- 新增个人任务收藏，支持别名、备注、搜索、分页和复制历史配置；收藏按用户隔离。(`2ce5d32`)
- 批量结果和 Canvas 运行树新增逐图迭代失败详情，可定位任务组、输入图片序号、迭代区域、失败节点和上游错误；可指定失败区域重试，复用成功图片结果。详情按需读取。(`0f6cac4`)
- 修复子任务已成功、汇总阶段图片生成失败时缺少重试入口的问题。任务组支持汇总阶段重试和批量重试，沿用失败节点恢复机制，保留原任务、稿件与成功子任务；已发布、发布中及含外部写入的流程有明确保护。(`823d537`)
- 恢复按工作流显示批量调度历史；限制历史查询和旧结果复用的内存开销，避免为少量结果加载大量历史数据。(`b015f7c`, `514bf40`)
- Canvas 批量执行默认并发调整为 32，上限为 100；实际并发仍受任务依赖、模型服务和运行资源约束。(`67a4545`)

### 内容池编辑、导入与响应速度

- 内容池新增手动图文编辑，可暂存和保存标题、正文及图片调整；保留未保存提示、作者权限和重新采集时的手动字段保护。(`c47b797`)
- 编辑器支持图片拖入、粘贴，以及图片预览缩放和拖动查看。(`800bc39`)
- 修复内容池浏览状态恢复，并减少重复列表与统计请求；批量内容读取按所选范围查询，减少重复整库读取。(`5f15c7d`, `5184ab5`)
- 成员可以向其他账号的内容库导入素材，导入内容归目标库所有者；内容查看与管理继续受原有权限限制。(`45a7453`)
- 内容池新增飞书编号导入入口，Canvas 内容采集也可按飞书编号读取素材。(`018ec49`, `f37efb1`)

### 飞书附件与原创检索

- 修复不同图片使用相同文件名时被覆盖的问题，导入保留每个附件，并按源记录顺序排列。对应任务已记录真实八图导入验证。(`8ef1efd`)
- 飞书发布适配新目标表的文本标签字段，避免按错误字段类型写入。(`0a0df07`)
- 原创创作接入 Magpie MCP 搜索，新增受保护的配置与搜索引用处理；离线和模拟浏览器检查已完成，真实密钥与检索验收仍待完成。(`b30d64b`)

### Canvas 节点、尺寸与素材选择

- 新增动态 Switch Any 节点，可在不同类型输入之间选择输出；运行时校验索引和实际数据类型，无法匹配时明确报错。(`3cfd902`)
- 文字拼接节点按连接情况逐步扩展，最多支持 16 路输入。(`1e3fb9e`)
- 图片库节点分别保存筛选条件和素材顺序，避免多个节点相互覆盖；下游使用所选素材的顺序快照。(`25a51d2`)
- 修复高分辨率图片预处理，覆盖 100 MP 输入和 8K 输出相关检查；取消旧的 4K 请求拦截，合法尺寸按当前服务商协议传递。服务商是否支持具体尺寸仍需分别确认。(`3deac17`, `67f17bc`)

### 图片预览、图集与审核台

- 图片预览按可用空间完整显示，并支持调整预览窗口大小；Canvas 共用预览组件，预览操作与画布快捷键相互隔离。(`1cf656d`, `2c05db0`)
- 图集切图保留已解码图片和预览弹窗，减少切换时闪烁；删除当前图片后继续查看下一张。(`7b8aacd`, `609332b`)
- 修复图集子树显示和重命名后当前图集不可见的问题。(`b35d22b`)
- 审核台按浏览器账号记住已应用的筛选条件，恢复完成后再查询；保留清空、日期、链接参数和账号切换的独立处理。(`4fc6863`)

### 本地运行与资料整理

- 本地启动器将服务进程与编辑器任务的生命周期分离，并将 Node 堆上限提升至 24 GiB；相关 Windows 进程归属和本地启动检查已完成。(`498682c`)
- 已有任务记录本地 G9L 裁图及 MONA L05 文案导入的数量和校验结果。这些是本地资料操作证据，素材文件、文案数据库和备份不随 GitHub 代码推送。
