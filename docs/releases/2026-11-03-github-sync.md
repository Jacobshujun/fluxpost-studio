# FluxPost Studio 更新说明

## 2026-11-03 GitHub 同步

本次整理上次 GitHub 同步点 `f86fab7` 之后、截至 `8d2f75e` 的 102 个本地提交，覆盖 2026-10-26 至 2026-11-03 的功能、修复、验证与任务记录。该范围共变更 433 个文件，新增 31,278 行、删除 1,257 行；本说明及同步状态记录另计。

### Canvas 工作流与图片模型

- 新增 Qwen 图片生成节点，支持文生图、图生图和节点独立凭据；凭据通过服务端受控接口管理。离线协议、持久化和浏览器检查已通过，真实模型验收仍待完成。(`0b775c7`)
- 新增 Wonder Image 节点，支持按顺序输入参考图和 Yike 异步任务恢复；后续修复了参考图编号、请求格式及已有媒体重复注册的问题。已有媒体可复用，仍保留就绪检查。真实服务商与模型验收仍待完成。(`bc4c770`, `b207789`, `950f472`, `63925fb`)
- 所有节点均可设置启用、禁用或旁路，涵盖迭代区域、节点菜单、检查器和批量操作；无法确定转接关系时明确报错。(`df7b675`)
- 修复逐图迭代内部节点无法绑定批量参数的问题，支持按迭代区域选择内部字段，并将参数冻结到实际执行快照。(`adaf32d`)
- 修复文字节点编辑时画布视图跳动，以及缩小节点后状态区域占用过大的问题。(`ab78c70`, `4f375dc`)

### 内容池：内容库、子集与标签

- 新增按用户隔离的内容库和嵌套子集，支持默认库、内容加入多个集合、批量调整归属，以及 Canvas 按内容库和下级子集筛选素材。(`5d80b84`)
- 新增自由标签管理，支持颜色、重命名、合并、删除和批量编辑。内容池与图片素材库继续分别管理。(`5d80b84`)
- 修复内容库范围内的改写统计，将已审核和已发布内容纳入已改写数量。(`522b353`)
- 内容列表、统计和全选编号改为独立分页接口；列表去除采集原始大字段，内容库与单条内容编辑改为定向写入，减少整库读取和重写。(`ebfc7da`)
- 已记录的本地 PostgreSQL 测量中，4,692 条内容的列表请求约 960 毫秒、统计约 898 毫秒，列表响应约 66 KB。真实登录操作下的持续性能验收仍待完成；大索引和项目 JSON 的进一步拆分属于后续工作。

### 审核台：布局、排序与筛选

- 重整审核列表与编辑区布局，适配不同窗口宽度；恢复紧凑多图预览，图片按 3:4 展示、视频按 4:3 展示。(`4a78295`, `246ff0a`, `0428b64`)
- 普通稿件和系列卡片支持拖拽自由插入排序，包括缺图卡片；修复拖拽开始时源控件被禁用、导致排序失效的问题。拖拽期间的删除、重生成和上下移动会分别锁定。(`4a78295`, `725271b`)
- 新增可组合的结构化筛选，覆盖作者、车型、状态、平台、文字和时间条件；相对日期按北京时间计算，并固定分页使用的时间基准。(`4a78295`)
- 修复异步编辑时提示词或媒体状态被旧结果覆盖的问题，以及高级筛选弹窗透出底层图片和编辑内容的问题。(`72e77a6`, `505c9b9`)
- 相关布局与交互已通过隔离浏览器验证，包含三种主题、桌面和移动尺寸；图片比例与拖拽专项覆盖 45 个场景，拖拽另经真实鼠标操作验证。真实登录后的操作验收仍需继续。

- 附件上传新增进程内速率调度，并针对明确的附件写入限流错误执行有限次数重试；其他错误继续明确返回。(`58f48b1`)
- 本轮深入离线审查另外复现了 8 项尚未修复的问题：附件路径边界、发布保存覆盖新编辑、换图或排序后误跳过上传、部分视频失败被遗漏、删除稿件被排队快照恢复、新建记录编号保存过晚、补建记录继承旧附件成功状态、进度保存覆盖执行锁续期。
- 上述审查结果保留在 [飞书发布代码审查](../../.trellis/tasks/11-03-feishu-publish-owner-recovery/code-review-2026-11-03.md)。复现证明代码存在对应风险，不代表所有问题均已损害真实数据；基线通过也不代表这些问题已经修复。真实飞书发布验收仍待完成。
